# KNH INVEST s.r.o.

KNH INVEST s.r.o. develops and operates technology projects focused on digital infrastructure, automation, IoT, and data-driven services.

## SmartGovIOT

**SmartGovIOT** is a modular municipal IoT platform initiative focused on collecting, processing, integrating, and using operational data from buildings, infrastructure, utilities, and connected devices.

The project uses a structured engineering workflow built around GitHub for versioned technical implementation and Notion for project and product knowledge.

> Public repositories and organization profile content contain only information intended for public disclosure. Project source code, credentials, operational data, and customer-sensitive information remain protected in their appropriate systems.
